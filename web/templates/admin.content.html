First-time owner login setup

There is no default password. Only someone with access to this hosting project's private environment settings can provision an administrator.

  1. In your hosting project's environment variables, set ADMIN_PASSWORD to a unique password-manager-generated password (at least 16 characters; 24 or more recommended).
  2. On your own trusted computer, generate a private authenticator setup key with Python:
    python3 -c "import base64,secrets; print(base64.b32encode(secrets.token_bytes(20)).decode())"
    Save the output as ADMIN_TOTP_SECRET in hosting secrets. Add that same key manually to your authenticator as a time-based account named STRATEVO owner. Keep a secure recovery copy.
  3. For this owner setup, leave ADMIN_ACCOUNTS_JSON, ADMIN_TOKEN and STRATEVO_ADMIN_TOKEN unset. Existing named accounts or token aliases take priority: do not remove intentional settings without checking with your administrator.
  4. Apply the variables to the intended hosting environment and redeploy when authorized. Existing deployments do not automatically pick up changed settings.
  5. Sign in above as owner, using your password and the current six-digit authenticator code.

Never put credentials in chat, source code or browser storage. A GitHub ZIP does not include hosting secrets. If you lose access, an authorized hosting administrator must rotate the credentials; there is no public password-reset bypass.
