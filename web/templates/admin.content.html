First-time owner setup

Set ADMIN_PASSWORD (at least 16 characters) or ADMIN_TOKEN (at least 32 characters) in the hosting environment, then redeploy when authorized. The alias login name is owner. ADMIN_TOTP_SECRET is optional and recommended; enter a current code only if configured. Named accounts can instead use ADMIN_ACCOUNTS_JSON. No default password or public access exists. Keep all credentials out of source code and chat.
